# \# Personal Task Manager

# 

# Ứng dụng Web quản lý công việc cá nhân, hỗ trợ xác thực người dùng và lưu trữ dữ liệu đám mây theo thời gian thực.

# 

# \## Tech stack

# 

# \* \*\*Frontend:\*\* HTML, CSS và JavaScript thuần (Vanilla JavaScript).

# \* \*\*Backend \& Database:\*\* Supabase.

# 

# &#x20; \* \*\*PostgreSQL:\*\* Lưu thông tin tài khoản và các công việc của người dùng.

# &#x20; \* \*\*Supabase API:\*\* JavaScript giao tiếp với database thông qua thư viện `@supabase/supabase-js`.

# &#x20; \* \*\*Authentication:\*\* Đăng ký và đăng nhập bằng email/password.

# &#x20; \* \*\*Row Level Security (RLS):\*\* Thiết lập quyền truy cập để mỗi người dùng chỉ có thể xem, sửa và xóa công việc của chính mình.

# \* \*\*Git \& GitHub:\*\* Quản lý phiên bản code và lưu trữ project.
